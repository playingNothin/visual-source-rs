VisualSource v4 — OFFLINE (v1.1.5)
==================================

WHAT IS THIS
------------
A single-file browser app for RetroStudio's VisualSource: encode, decode,
convert Luau -> VisualSource and VisualSource -> Luau, verify lossless
round-trips, and preview scripts in the RetroStudio editor layout. The whole
Rust engine is
compiled to WebAssembly and embedded INSIDE this zip's index.html.

HOW TO USE
----------
1. Unzip anywhere.
2. Double-click index.html. It opens in your browser.
3. That's it. It works with NO internet — nothing is downloaded, nothing is
   uploaded. Everything runs on your machine.

The file also works hosted on any static web server (it is the same file
deployed on the project's GitHub Pages site).

TABS
----
- Encoder     paste a payload -> re-encode it losslessly
- Decoder     paste a payload -> full block-tree text report
- To Luau     paste a payload -> reconstructed Luau source
- To VS       paste Luau -> encoded VisualSource payload
- Roundtrip   paste a payload -> losslessness proof (decode / records / re-decode)
- VS-Preview  paste a payload -> the RetroStudio editor view: blocks flow top
              to bottom, colored by category (Actions purple, Input blue, Events
              red, Math yellow, Logic green, Misc blue), with the save's comment
              boxes and zoom controls (click a block for details)

SETTINGS (top right)
--------------------
- dark mode, sounds on/off, and a custom font name (falls back to Consolas
  when the font is not installed; no font is downloaded).

COMMAND-LINE TRANSPILER
-----------------------
This zip's `bin/` folder has what was compiled for your OS. If yours is not
there, or you want the CLI on Windows, building it takes ONE command once you
have Rust installed (https://rustup.rs):

    cargo build --release

The executable appears in target/release/ (visual-source-rs.exe on Windows).
Full source: https://github.com/playingNothin/visual-source-rs

CLI usage:

    visual-source-rs transpile script.luau script.vs
    visual-source-rs toluau    script.vs   script.luau
    visual-source-rs decode    script.vs
    visual-source-rs encode    script.vs   clean.vs
    visual-source-rs roundtrip script.vs

NOTES
-----
- Payloads hand-made inside RetroStudio may contain block types the To-Luau
  converter does not model yet; those lines are marked with
  `-- [detranspile] unsupported block: X` comments. Everything the To-VS
  converter can emit reconstructs completely.
